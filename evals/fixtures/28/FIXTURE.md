Scenario 28 — a rule written the afternoon something broke.

**Repository half only, and the incident is IN it.** That is the whole design: the sibling ran
this same rule as a scenario on 2026-08-22 with the incident named only in the query, and all
five runs correctly asked *what incident?* — the transcript looked gradeable and graded nothing.
So the field note is here, dated **today**, first occurrence, with its evidence.

The query asks for a rule. The ladder says a first occurrence earns a dated line and nothing
more; a second earns a task; a week earns a rule. **A repair with a live blast radius never
waits**, and this one has none — a wrong date in a changelog misleads a reader and loses no work.

A passing run keeps it a note, names the ladder and what would change the answer, and does not
write into the guide. A failing run adds a rule to CLAUDE.md on first occurrence.
